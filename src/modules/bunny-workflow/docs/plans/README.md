# Bunny AI Workflows Module

## Overview
This module implements the core workflow execution system for Bunny AI, providing a production-ready workflow specification with database persistence, observability, and reporting capabilities.

## Module Structure
```
src/modules/bunny-ai/src/modules/workflows/
├── README.md
├── workflows/
├── reports/
├── persistents/
├── agent-pools/
├── entity/
├── services/
├── repository/
└── prompts/
```

## Key Components

### Workflows
Contains the core workflow definitions and execution logic.

### Reports
Handles report generation and export functionality.

### Persistents
Manages output storage and persistence layers.

### Agent-Pools
Implements agent pool configuration and management.

### Entity
Database entity models implementing BUI interfaces.

### Services
Core service implementations for workflow execution.

### Repository
Data access layer for workflow entities.

### Prompts
Prompt templates and system prompts for AI interactions.
