# Version 5.3.0 — App Builder VSCode Redesign, Specs & Docs, Schema & Board Upgrades

- **Version:** v5.3.0
- **Release dates:** 2026-10-09, 2026-10-12, 2026-10-13, 2026-10-16, 2026-10-17, 2026-10-21
- **Commits:** `e7df849` → `a24cb21` (base `e7df849`, v5.2.0)
- **Apps:** Bunny Developer, LemonCoder, Bunny Book, Catalog
- **Stats:** 159 files changed, 17,195 insertions(+), 4,964 deletions(-)

## Summary

Version 5.3.0 is a large Bunny Developer release. The **App Builder** is
redesigned into a **VSCode-style workspace** with a title bar, explorer sidebar,
tabbed editors and a standalone SPA shell, and gains a full set of **AI
assistants** (design, resource, record) plus schema-driven field/column filling.
The **Outline** module becomes **Docs** and the **Architecture** module becomes
**Specs**, both rebuilt with new list/detail routes, a document-mode system, an
AI refine wizard and drag-and-drop topic ordering. The **Schema Builder** gains
a documentation view, a real index editor and a relation-column shortcut, and
the **Project Management** module gains board templates, a list view, board
keys and configurable card chips. **LemonCoder** receives a rewritten
SEARCH/REPLACE edit engine that fails loudly on ambiguous edits and cuts
output tokens.

> **Breaking changes:** the `Outline` module is now `Docs` and `Architecture` is
> now `Specs` (routes, Dexie tables and persisted `subsystem` values renamed).
> Dexie migrations v6–v8 migrate existing data automatically.

## Highlights

### Bunny Developer — App Builder VSCode Redesign

- The designer is now a **VSCode-style workspace** implemented in three new
  components:
  - `BDAppBuilderShell` — title bar with **File / Edit / View** menus, back
    arrow, sidebar toggle, right-aligned actions and a status bar. Menus close
    on outside click or Escape.
  - `BDAppBuilderSidebar` — collapsible **Resources** explorer showing field
    counts (hover reveals delete) plus an **App** section (Overview / Settings).
    Collapses to a 12-wide icon rail.
  - `BDAppBuilderTabs` — tabbed workspace for open resources.
- New `BDAppCreate` and `BDAppSettingsModal` components (app creation and app
  settings are now first-class flows instead of inline forms).
- **Project-level layout switch**: `BDProject.builderLayout` (`full` | `shell`)
  is settable from project settings — `full` renders the designer as a
  dedicated full-screen workspace, `shell` embeds it in the Bunny Developer
  chrome. Defaults to `shell`.

### Bunny Developer — App Builder AI Assistants

- **Design AI** (`BDAppDesignAI`) — fills app meta (name, slug, path,
  description, brand, logo, theme) and resources; sections `meta` and
  `resources` can be toggled independently. Backed by `bdGenerateAppDesign`.
- **Resource AI** (`BDAppResourceAI`) — fills a single resource's meta, form,
  table and connections; sections `meta`, `form`, `table`, `connections`.
  Backed by `bdGenerateAppResource`.
- **Record AI** (`BDAppRecordAI`) — generates sample/seed records with
  relation and select options resolved from the schema. Hidden, file-upload and
  image fields are skipped. Backed by `bdGenerateAppRecord`.
- Full-app generation via `bdGenerateApp`.

### Bunny Developer — App Builder Data Model & Forms

- New connection model: `BDAppConnection` (`oneToOne` / `oneToMany` /
  `manyToMany`) with `deriveConnectionFields`, `deriveConnectionColumns`,
  `findInverseConnection`, `connectionsFromModelRelations` and
  `collectConnectionReferences`; connections can be derived automatically from
  schema relations.
- New **form behavior** `BDAppFormBehavior` (`close` | `view`) resolved by
  `resolveFormBehavior` — "Save & close" or "Save & view record".
- New **id rules**: `stampGeneratedId` with incremental / uuid / manual
  strategies plus `nextIncrementalId`.
- New **schema fill** (`BDAppSchemaFill`) — pick fields and columns from the
  attached schema, with separate selection sets, "fill all" and a "fill from
  schema" flow; `defaultSchemaSelection`, `schemaSelectionFromResource` and
  `applySchemaSelection` preserve manual entries and append newly selected
  properties in model order.
- New helpers `BDAppFieldSelect`, `BDAppPropertyPicker` and `BDAppFiller` for
  field selection and form filling.
- New column formats (badge, icon, image, color, since, money, numeric, tags,
  select, toggle, progress, action) and reactive rules `BDAppReactiveRule`.
- `BDApp.Types.ts` gained ~713 lines of AI-draft types (`BDAppFieldDraft`,
  `BDAppColumnDraft`, `BDAppConnectionDraft`, `BDAppResourceDraft`,
  `BDAppDesignDraft`) and conversion helpers; `BDAppBuilder.Server.ts` gained
  ~798 lines of new server actions.

### Bunny Developer — Standalone App SPA Shell

- All three "open as application" entry points (title bar **Open**, **File →
  Open as application**, Overview **Open as application**) now open the app in
  a **new browser tab** via `window.open`, leaving the designer intact.
- New `BDAppStandaloneShell` provides the SPA chrome: fixed header, brand
  logo/name, `App / Resource` breadcrumb, responsive sidebar (`w-56` expanded /
  `w-12` icon rail on `md+`, overlay drawer below `md`), a sidebar footer with
  record stats and a single scrollable content pane.
- The render layout (`/modules/bunny-dev/render/[appId]`) is now
  `h-dvh overflow-hidden` so the shell owns all scrolling.
- The rendered resource table gained a sticky header, hover/banded rows,
  truncated values with tooltips and a `{rows} of {total} records` footer.

### Bunny Developer — Specs (renamed from Architecture)

- New routes: `/specs` (group list), `/specs/{groupId}` (document list) and
  `/specs/{specId}` (document detail) — a three-level grouped list → detail
  pattern replacing the old two-pane page.
- **13 document types** (`architecture`, `plan`, `adr`, `rfc`, `design`, `spec`,
  `roadmap`, `runbook`, `postmortem`, `readme`, `changelog`, `guide`,
  `proposal`) and **10 statuses** (`draft` … `archived`).
- New **document mode** `BDSpecDocMode` — `single` (one free-form body) or
  `sectioned` (ordered titled sections). Legacy rows infer their mode via
  `inferDocMode`.
- New `BDSpecSectionsEditor` — per-section heading level (H1–H6), title,
  summary (TL;DR), per-section view/edit toggle and body editor, plus a
  "View all / Edit all" bulk toggle.
- New `BDSpecCreateModal` — create a document with its body already authored,
  with a live Markdown preview.
- New **AI Document Assist · Refine** wizard (`BDSpecRefine`) — setup →
  questions → review. Per-type refinement suggestions, four options per
  question with a recommended option first, multi-turn refinement, and a
  Retry / Finish now / Accept & continue review screen. Applying preserves
  section ids and regenerates anchors.
- AI generation (`bdGenerateSpec`) now requests 300–500 word information-dense
  sections with a lead paragraph, sub-points, explicit trade-offs and a
  comparison table; the token budget was raised to 16,000 (32,000 for
  multi-variant) to stop long documents from truncating.
- **Variants**: "Create variant" clones a document into a named variant family;
  comparison moved from a modal to a `?compare={otherId}` route that renders a
  side-by-side Markdown comparison.
- Exports: markdown, standalone HTML (Tailwind CDN, Inter / Space Grotesk /
  JetBrains Mono, `marked` GFM, print-to-PDF button), **AI Handoff** and copy
  to clipboard.

### Bunny Developer — Docs (renamed from Outline)

- New routes: `/docs` (document table with type, topic count and status) and
  `/docs/{docId}` (editor).
- **12 doc types**, **5 statuses** (`draft`, `review`, `published`, `outdated`,
  `archived`), **14 topic types** and **21 content block kinds**.
- **Drag-and-drop topic reordering** via native HTML5 drag-and-drop (no extra
  dependency) — each sibling level reorders independently, with an insertion
  line indicator, grip handle as the only drag initiator, optimistic ordering
  and a "Order saved" toast.
- Topic tree actions: select a topic, add a child topic, delete a topic.
- Doc metadata row with inline name/title/slug editing and a live
  "{n} topics · {type}" readout; "New doc" dialog starts with a name only and
  folds the rest behind "More options".
- Markdown export now emits a **table of contents** (unless disabled in doc
  settings) and nests topics by heading depth. Exports: MD, HTML, JSON and
  preview.

### Bunny Developer — Schema Builder

- New **Schema documentation view** (`BDSchemaDoc`) — a read-only modal for a
  schema group with model cards, column tables (type, nullable, PK/UQ keys,
  default, notes), relation lists with join notation
  (`Target.ownerKey ← ThisModel.foreignKey`) and index lists.
- New **index editor** (`BDSchemaIndex`) — name, type and a checkbox column
  picker with Select all / Clear, replacing the free-text comma-separated
  input.
- New **relation column shortcut** (`BDSchemaRelationColumn`) — creates a FK
  column plus a `belongsTo` relation in one step, with a live preview and an
  automatically added inverse `hasMany` on the target model.
- The model editor's **relations are now a table** (type, target model, name,
  references, foreign key) scoped to the same schema group, with a Sparkles
  button that auto-suggests the relation name, owner key and foreign key.
- New model creation is a **client-side draft** saved on submit; the duplicate
  "Add model" button was removed and "Delete model" was removed from the form
  (deletion is a list action only).
- Export is now **group-scoped** — only the active schema group is exported,
  with group-derived filenames (`{group-slug}.prisma`).
- New naming helpers: `snakeCase`, `camelCase`, `pluralizeWord` (`category` →
  `categories`), `suggestRelationName`, `suggestForeignKey`, `uniqueForeignKey`
  and `buildRelationColumn`.

### Bunny Developer — Project Management

- New **board templates** and creation dialog (`BDBoardDialog`) — Kanban,
  Scrum, Bug tracking and Blank templates, with a sortable section editor
  (rename, category, colour, insert-below, remove) and an auto-derived board
  key (`My Board` → `MYB`).
- New **list view** (`BDBoardList`) alongside the kanban board, groupable by
  Section, Priority, Type, Assignee or any `select` custom field, with
  collapsible groups.
- New **card chips** (`BDTaskChipRow`) — configurable badges (key, type,
  priority, story points, assignee, due date and custom fields) rendered on
  both kanban cards and list rows.
- New `select` custom field type with `options`, editable in board settings and
  rendered in the task drawer.
- **Board-scoped task keys** — task ids are now `{board-key}-{n}` (e.g.
  `MYB-12`) instead of project-wide numbering, backed by a Dexie **v8**
  migration that backfills a unique key per board.
- Board settings gained a **Card chips** section and a board key field.

### Bunny Developer — Diagram Builder

- New shared **`BDDiagramCanvas`** component — an interactive Mermaid viewer
  with fit-to-viewport scaling computed from the painted SVG, editable zoom
  percentage (100% = fit, ±25% steps, clamped 25–400%), a Fit button,
  grab-to-pan, a `ResizeObserver`-backed baseline and an imperative handle
  (`getPreviewNode`, `getNaturalSize`, `fit`).
- The diagram editor is now a **two-column full-height workspace** on `xl` —
  the editor scrolls independently while the preview stays pinned — with a
  floating **Preview** button and modal canvas on smaller screens.
- **Batch AI generation** — the AI can pick types for a requested total
  ("auto") or the user picks types and counts; the server enforces an exact
  count with up to three top-up attempts and a hard cap of 20 diagrams.
- The Schema Builder ERD viewer was rewritten on top of `BDDiagramCanvas`
  (~250 lines of bespoke zoom/pan removed).

### Bunny Developer — File Management AI

- New **AI Assistant** for files (`BDFileAI`) — describe a change, get a set of
  anchor-based patches, review them in a unified diff (`BDDiffView`) and
  accept or reject. Accepting persists the file immediately (size and revision
  updated).
- New client-safe patch engine (`BDFile.Patch`) — patches replace the
  inclusive region between two verbatim patterns, applied sequentially with
  exact → trailing-whitespace-insensitive → whitespace-collapsed fuzzy
  matching. A missing anchor throws `BDFilePatchError` with the patch number
  and the pattern it looked for.

### Bunny Developer — Shared Components & Theming

- New `BDSortableList` — config-first drag-and-drop list with optimistic
  ordering, loading and empty states (used by the board dialog).
- New `BDDiffView` — unified line diff with left/right line numbers and
  add/remove colouring, styled to match the dark code editor.
- `BDStyle.css` gained a full theme token set (`--bd-primary-hover`,
  `--bd-primary-soft`, `--bd-on-primary`, `--bd-color-*`) plus a `.bd-app-header`
  gradient. Under `[data-bd-theme]` the tokens are re-derived with `color-mix()`
  from the app's configured primary colour, so an app's own colour now themes
  its header, buttons and badges when opened standalone.
- `BDModal` gained `closeOnBackdrop`; `BDForm`/`BDSchemaForm` gained a
  secondary submit action; `BDButton` now forwards refs and uses CSS variables;
  `BDBadge` moved to CSS classes; `BDIconButton` is wrapped in a HeroUI
  `Focusable` for tooltip correctness.

### Bunny Developer — Data Migrations

- **Dexie v6** renames `outlines` → `docs`, `architectures` → `specs` and
  `architectureGroups` → `specGroups`, rewrites attachment foreign keys
  (`outlineId` → `docId`, `architectureId` → `specId`) and persisted
  `subsystem` values (`outline` → `docs`, `architecture` → `specs`).
- **Dexie v7** drops the pre-rename tables.
- **Dexie v8** adds the `key` index to `boards` and backfills a unique
  per-project board key.
- The legacy `ai/tasks/tasks.yaml` backlog was removed.

### LemonCoder — Hardened Edit Engine & Token Savings

- New **SEARCH/REPLACE engine** (`LCApplyEdits`) with a five-step fallback
  ladder: exact → **anchor match** → whitespace-agnostic → trailing-whitespace-
  agnostic → partial-block. The anchor strategy uses the first and last
  non-blank lines of the `Search` block as unique line-leading anchors.
- **Ambiguity is now a hard error** — a `Search` block matching multiple
  locations throws a clear message instead of silently applying the last
  occurrence. An empty `Search` block also throws.
- New shared **edit output rules** (`LCPromptMode.EditRules`) used by both the
  Code and Agent prompts, so the two can no longer drift. `Search` is now
  1–3 anchor lines and `Replace` covers the whole inclusive region.
- **Output tokens cut**: for existing files the model now returns `Edits` and
  an empty `Content` instead of restating the whole file. Stashed file content
  is capped at 20,000 characters, and token usage is logged per request.
- **Save chat fix**: switching from the file view to chat now saves a dirty
  buffer first, and switching back to the file view no longer discards unsaved
  edits by reloading from disk. Failed saves now surface a toast.
- `docs/FILE_DIFF.md` was rewritten to document the new strategy ladder.

### Bunny Book (Bunny AI)

- New **author select field** for the book form — a custom field renderer
  listing existing authors with an inline "Create & Select" panel that
  auto-opens when no authors exist.
- The settings page was simplified to a **Preferences** page backed by the
  shared Helix provider selector, persisted in a new `aiSettings` Dexie table
  (**version 9**).
- The book reader modal now resets scroll position when a chapter is opened.

### Catalog & System

- The Bunny Developer catalog entry now advertises **docs, specs** in place of
  outlines and architecture docs.
- New dependency `react-aria-components@1.18.0`; new npm scripts `clean` and
  `build:fresh`.
- Added `docs/Requests/request-1.md` (schema builder) and
  `docs/Requests/request-2.md` (app builder) as the source requests for this
  release.
