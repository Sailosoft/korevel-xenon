# Version 5.2.0 — BunnyBook Outlines & Topics, BunnyDeveloper Grouped Pages, Shell Redesign & AI Generation Modes

- **Version:** v5.2.0
- **Release dates:** 2026-10-06, 2026-10-07, 2026-10-08
- **Commits:** `6a8874c` → `915c6c0` (base `f4c5f1d`, v5.1.0)
- **Apps:** Bunny Book, Bunny Developer, Helix, System
- **Stats:** 128 files changed, 11,808 insertions(+), 2,033 deletions(-)

## Summary

Version 5.2.0 introduces **Outlines and Topics** to Bunny Book — a structured
generation workspace built on the Books engine — and reworks **Bunny Developer**
navigation into grouped list → detail pages with a new Diagram Group level and
Architecture Groups. The Bunny Developer shell gets a full visual redesign
(dark dotted sidebar + blue gradient header) and every AI generation panel now
supports **create / append / update / replace** with a target selector. Helix
gains multi-turn chat history and a refreshed DeepInfra model list.

## Highlights

### Bunny Book — Outlines (new)

- New module at `src/modules/bunny-ai/src/modules/outlines` with a list page and
  a detail page (`/modules/bunny-ai/outlines/{id}`).
- An **Outline** is a `books` row discriminated by `kind: "outline"`, carrying an
  outline-level instruction (`additionalPrompt`), generation type/mode, an
  optional selected Topic (`topicId`), optional `minItems`/`maxItems` bounds, and
  an editable markdown `summary`. Its items are ordinary `chapters` rows scoped to
  the outline's book id.
- **11 Generation Types**: `guide`, `architecture`, `discussion`,
  `lecture_lesson`, `study`, `exam_helper`, `tutorial`, `reference`, `roadmap`,
  `research`, `workshop`.
- **7 Generation Modes**: `sequential`, `chain_of_thought`, `control`,
  `parallel`, `iterative_refine`, `critique`, `consolidate`.
- **Structure generation**: a mode-agnostic AI call
  (`buiOutlineServerGenerate`) returns
  `{ summary, items: [{ number, title, description, additionalPrompt? }] }`, with
  conflict handling (overwrite / skip / extend), optional topic insertion, and
  summary replace/append.
- **Item content pipeline**: per-row or batch writing through a shared server
  action. Modes control the context algorithm (full map, prior turns, chosen
  controls, or artifact-only), with a type × mode framing.
- **3-wide parallel pool**: since Next.js serializes Server Actions per client,
  the `parallel` mode calls a Route Handler
  (`/api/bunny-ai/outlines/item-content`) to genuinely run three items at once,
  with a live "Parallel Writing In Progress" modal.
- **Guided Refine wizard**: scope → critique (typed findings: insert, merge,
  reorder, refine) → apply (dry-run, then a single Dexie `transaction("rw")` for
  insertions, merges, reorder, contiguous renumber, and reference remap) →
  iterative refine (bounded passes with a diff word-change stop).
- **HTML export** reuses the Books export engine and `books/html-templates/*`
  with a template picker, live iframe preview, and download.
- **Inline meta editing** from the detail card (title, type/mode, topic, author,
  limits, description, instruction, summary).

### Bunny Book — Topics (new)

- New module at `src/modules/bunny-ai/src/modules/topics` with a `topics` Dexie
  table (database version 8).
- A Topic is a small reusable `{ id, title, description }` record that can be
  created manually or AI-generated (`buiTopicServerGenerate`) and used to seed any
  number of outlines via `books.topicId`.
- Shares the same 11 generation types as Outlines.

### Bunny Book — Navigation, Dashboard & Cascade Delete

- Sidebar gains an **Outline** section with **Outlines** and **Topics** entries.
- Dashboard adds an **Outlines** stat card (grid widened to 5 columns); the
  **Books** count now excludes outlines (`kind !== "outline"`).
- Deleting a book or outline now cascades: a Dexie `books.hook("deleting")`
  removes all chapters/items where `bookId === pk`, covering repository,
  `panelDelete`, and direct db deletes from a single hook.
- The Books entity now carries `kind` and `topicId`, and the book repository
  drops cascade cleanup in favor of the shared hook.

### Bunny Developer — Grouped List → Detail Pages

- Replaced the combined list + editor pages with a two-step pattern (feature root
  lists containers with **Open/View**; the deep route shows only that
  container), now rendered inside the normal project shell.
- **Schema**: `/schema` groups + **Open** → `/schema/[groupId]` models + editor.
- **App Builder**: `/app` apps + **View** → `/app/[appId]` app editor.
- **API Design**: `/api` groups + **Open** → `/api/[groupId]` operations + editor.
- **Diagram**: `/diagram` groups → `/diagram/[groupId]` diagrams → 
  `/diagram/[groupId]/[diagramId]` editor (new 3-level navigation).
- **Architecture**: `/architecture` groups → `/architecture/[groupId]` documents
  + inline editor + variants (new Architecture Groups level).
- New shared `BDGroupList` component and `BDBackLink`; each list page hosts its own
  **New** and AI generation actions.

### Bunny Developer — Data Model & Migrations

- New `BDDiagramGroup` and `BDArchitectureGroup` domains, `groupId` added to
  diagram/architecture records.
- New Dexie tables `diagramGroups` / `architectureGroups` and repositories, plus
  cascade hooks (deleting a group deletes its children) and project-scoped table
  registration.
- Migration **v4** (diagram groups) and **v5** (architecture groups) backfill
  legacy rows into a per-project `Default` group.
- Removed the now-unused `BDModuleLayout` and its exports; `projects/[projectId]`
  always renders `BDProjectShell`.

### Bunny Developer — Shell Redesign

- Sidebar restyled as a deep-navy blue gradient with a dotted texture and
  light-on-dark content; header is a blue gradient bar with white labels/icons
  and translucent controls.
- Centralized via `BDStyle.css` (`.bd-shell-sidebar`, `.bd-shell-header`) and
  `BDShell.config.ts` tokens consumed by both the outer and inner shells.

### Bunny Developer — Unified AI Generation Modes

- Every generation panel now supports **create / append / update / replace**.
- Non-create modes show a second **target selector**; the full target record is
  serialized into the prompt (`bdSerializeTarget`, capped) and merge/upsert or
  replace semantics are applied per subsystem.
- New client-safe `BDGeneration.Mode.ts` (mode labels + guidance + serializer);
  `BDGenerationPanel` extended with `targets`, `targetLabel`, `targetModes`, and
  `buildTargetContext`.
- Agent Manager uses `targetModes={["update","replace"]}` (append adds agents to
  the project with no target).

### Helix

- Added `doChatWithHistory` to the service interface for raw OpenAI-style
  messages arrays that preserve assistant turns (used by Chain-of-Thought).
- Refreshed the DeepInfra model list (new Claude Opus, DeepSeek V4.1/vision,
  Gemini, Gemma turbo, Ling, Mistral, MiniMax M3, Nemotron, Qwen 3.5/3.8, MiMo
  2.6, and GLM-5.3 entries).

### System

- Pinned the Docker base image to `oven/bun:1.4.2-alpine`.
- Expanded the README Docker workflow docs (build-before-up guidance, logs,
  cache-busting, detach/foreground usage).
