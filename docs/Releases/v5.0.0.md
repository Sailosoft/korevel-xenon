## Summary

Version 5.0.0 introduces **Bunny Developer** (`/modules/bunny-dev`), a local-first
(Dexie) developer decision workspace for brainstorming and planning business
software applications. Projects act as the container for every builder, and all
records persist in the browser via DexieDB with AI generation routed through
Helix server actions.

## Highlights

### Module Shell & Core

- New module at `src/modules/bunny-dev` with a two-level layout: a main layout
  listing projects and a project layout listing all builders.
- Project core (list, settings, context, hooks, repository) plus a config-first
  shell (sidebar, header, module layout).
- Shared `BD*` component kit: buttons, icon buttons, forms, schema forms, lists
  (config-first data table with sorting, search, pagination, bulk actions),
  modals, drawers, toasts, badges, context menu, code editor, Markdown view,
  WYSIWYG editor, async boundary, empty states, and status dots.
- Local-first persistence (`BDDatabase`, `BDRepository`, `BDMigration`) on Dexie.
- AI Settings context wired to Helix; all interfaces/types prefixed `BD`.

### Schema Builder

- Model, property, and relation editing with schema groups for variants.
- **Prisma export** hardened: fallback model names, skips unnamed
  properties/relations, slugified `@@map` table names.
- **ERD viewer** (new): read-only Mermaid `erDiagram` per group with
  fit-to-viewport zoom (±25% steps), grab-to-pan, SVG/PNG/Mermaid export, and
  save-to-Diagram-Builder.
- Mermaid ERD generation helpers (`BDErdExport.ts`).

### App Builder

- Filament-inspired resource designer: resources, forms, and tables that render
  a working CRUD app.
- **Relation manager** (new): one-to-one, one-to-many (inline child CRUD with
  search/pagination), and many-to-many (searchable attach/detach + reorder).
- **Standalone render route** (new): `/modules/bunny-dev/render/[appId]` runs a
  generated app outside the builder, with a back-to-metadata action.
- AI-assisted generation for resources and fields.

### API Design

- Document layout and Postman-like mock layout with request tabs
  (params/headers/body).
- **API groups** (new) for organizing operations.
- **Faker-powered mocking** (`@faker-js/faker`): each fakeable field picks a
  "fake as" generator and the whole mock can be regenerated.
- Export to HTML and AI generation of operations.

### Diagram Builder

- Type-specific node/edge editors; diagram type is chosen once at creation and
  then locked.
- Raw Mermaid source override with live preview, AI generation from the header,
  and `.mmd` / `.md` / `.svg` export.
- Expanded diagram types and direction support.

### File Management

- Google Drive-style full-page manager: grid/list views, folder state in the
  URL, dedicated editor route.
- Upload with language detection, media preview in a **viewer modal**
  (images/video/audio inline, PDFs in an iframe, Markdown, read-only code).
- **Selection mode** for bulk move / copy / download / delete, plus a
  target-folder modal.
- **Password-protected files**: protect / unlock / remove flows with a single
  dialog; session-only unlock (`BDFile.Lock`), gating view/edit/download.

### Project Management

- JIRA-style kanban boards with task drawer.
- **Threaded task comments** (new): virtualized one-level threads with a WYSIWYG
  composer.
- **Board settings** (new): rename board, manage sections/columns, manage custom
  fields.
- **Project management settings** (new): rename and reorder the project's boards.

### Outline & Architecture

- Outline builder with AI generation and Markdown/JSON/text export.
- Architecture builder with sections and WYSIWYG editing; **Markdown and
  standalone Tailwind-styled HTML export** (`toArchitectureMarkdown`,
  `toArchitectureHtml`).

### Agent Manager

- Agent CRUD with **handoffs** and **batch proposals** for delegating work to
  agents across builders.
- Bunny Developer agent definition (`ai/agents/agent-bunny-dev.md`) and a YAML
  task backlog (`ai/tasks/tasks.yaml`).

### System / Catalog

- Catalog: added the **Bunny Developer** card (`id: 13`) to the application
  catalog.
- Helix: structured JSON generation now mandates compact, newline-free output.
