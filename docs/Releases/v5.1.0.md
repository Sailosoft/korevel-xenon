- **Version:** v5.1.0
- **Release dates:** 2026-10-03, 2026-10-06
- **Commits:** `692b9cc` → `bd8a7da` (base `28adce7`, v5.0.0)
- **Apps:** Bunny Studio, Bunny Book, Bunny Developer, System
- **Stats:** 27 files changed, 2,942 insertions(+), 537 deletions(-)

## Summary

Version 5.1.0 upgrades **Bunny Studio's Image Library** with day grouping,
multi-select bulk delete, and a gallery-style preview that navigates across the
whole collection, and fixes image download filenames so same-minute downloads
no longer overwrite each other. **Bunny Book** gains real math rendering with
KaTeX across chapter readers and the HTML export engine, plus a new Bunny
export template and a reworked GitHub template replacing Facebook. A
**Bunny Developer** hotfix makes AI generation settings reactive, and the whole
suite is now packaged with a **multi-stage Docker** build.

## Highlights

### Bunny Studio — Image Library & Downloads

- **Day grouping** (full library): images are bucketed by their local generation
  day with `Today` / `Yesterday` / long-date headers, and each day header has a
  select-all checkbox.
- **Multi-select + bulk delete** (new): an explicit **Select** toggle enables
  selection mode with a sticky toolbar that deletes every selected image in one
  operation (backed by a new `BSImageRepository.deleteMany` bulk IndexedDB call).
- **Gallery preview** (new): one shared modal navigates previous/next (wrapping)
  across the ordered library, with `←` / `→` arrow-key support and an
  `n / total` position indicator. The generator's result batch gets the same
  wrapping gallery preview.
- **Selection-aware cards**: `BSImageCard` now shows a checkbox and toggles
  selection instead of opening the preview while in selection mode, hiding its
  hover action bar.
- **Collision-free download names**: new `buildImageDownloadName` produces
  `bunny-ai-YYYYMMDD-HHMMSS-<fullId>.png`. The full asset id is kept (never
  sliced) so images generated in the same second can no longer overwrite each
  other — the previous 8-char UUIDv7 slice only changed about every 65 seconds.
- The generator's compact 4-image preview stays a flat, non-selectable grid;
  grouping and selection apply only to the full library.

### Bunny Book — KaTeX Math Rendering

- Chapter read content and the chapter read modal now render math via
  `remark-math` + `rehype-katex`, and the Bunny Book layout imports the KaTeX
  stylesheet (`katex/dist/katex.min.css`).
- The **HTML export engine** parses with `Marked` + `marked-katex-extension`
  (`throwOnError: false, strict: "ignore"`) and injects the KaTeX stylesheet into
  exported documents so pre-rendered math displays correctly.
- New `normalizeMathMarkdown` de-indents math-only lines so `marked` no longer
  treats them as indented code blocks, while leaving fenced code untouched.
- Removed the old `$\rightarrow$` / `\rightarrow` string replacement now that
  real math is rendered.
- Export sidebar now includes **chapter excerpts** (`buildExcerpt`, ~160 chars)
  and the book title.
- Chapter numbers are normalized in the export service
  (`Number.isFinite(Number(ch.number))`).

### Bunny Book — Export Templates

- New **Bunny-branded** template (`bui.html-template.bunny.ts`) added to the
  available template list.
- The Facebook template was removed and replaced by a rebuilt **GitHub** template
  (`bui.html-template.github.ts`) with an improved reader layout.
- `BunnyFormBuilder` now coerces `number` fields to numbers on change.

### Bunny Developer — AI Generation Hotfix

- `BDAISettings.Context` now reads the `aiSettings` singleton reactively with
  `useLiveQuery`, so provider/model selections made with
  `HelixAIProviderSelector` propagate to every generation panel immediately.
- `BDGenerationPanel` honors a per-project override (`project-{id}`) ahead of the
  global AI config, reactive to changes.
- Helix DeepSeek model list fixed: `deepseek-v4-flash` → `deepseek-flash`.

### System — Docker Support

- New **multi-stage Dockerfile**: `deps` → `dev` (hot reload) → `builder` →
  `runner`, using `oven/bun:1-alpine` to install/build and a minimal
  `node:20-alpine` standalone runner with a non-root user and healthcheck.
- New `docker-compose.yml`: production `web` service (`3052:3000`) and a
  `dev` profile `web-dev` service (`3050:3000`) with bind-mounted source,
  hot reload, and polling.
- `next.config.ts` now sets `output: "standalone"`.
- Added `.dockerignore` and Docker usage docs in the README
  (`NEXT_PUBLIC_BUNNY_STUDIO_API_TOKEN` is passed as a build arg and requires a
  rebuild to change).
- Added KaTeX dependencies: `katex`, `marked-katex-extension`, `rehype-katex`,
  `remark-math`.
